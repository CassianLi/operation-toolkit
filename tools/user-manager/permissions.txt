============================================================
                         系统权限组配置一览
============================================================

■ 开发人员 (developers)
  描述: 开发人员用户组，拥有代码开发和调试权限
  目录权限:
    - /usr/local/src (源码目录): 读写(rwx)
    - /opt (第三方软件目录): 只读(r-x)
    - /var/log (系统日志目录): 只读(r-x)
    - /tmp (临时目录): 读写(rwx)
  Sudo命令:
    - /bin/systemctl status *
    - /bin/systemctl restart *
    - /bin/systemctl stop *
    - /bin/systemctl start *
    - /bin/top
    - /bin/htop
    - /bin/ps
    - /bin/kill
    - /bin/killall
    - /usr/bin/tail
    - /bin/less
    - /bin/cat
    - /bin/grep
    - /bin/find
    - /bin/ls
    - /bin/dmesg
    - /bin/journalctl
    - /usr/bin/lsof
    - /bin/netstat
    - /bin/ss
    - /bin/mount
    - /bin/umount
