# MySQL 5.7 数据库手动恢复指南

## 概述
本指南详细说明如何手动恢复MySQL 5.7数据库从备份文件 `mysql57_sysafari_20250723.qp`。

## 前提条件
- 已安装podman和podman-compose
- 备份文件位于：`/data/databases/mysql/backups/mysql57_sysafari_20250723.qp`
- 数据目录：`/data/databases/mysql/data`

## 方法一：使用podman-compose启动后手动恢复

### 1. 启动MySQL服务
```bash
cd /path/to/tools/db-tools
podman-compose up -d mysql57
```

### 2. 等待服务完全启动
```bash
# 检查容器状态
podman-compose ps

# 查看日志确认服务已启动
podman-compose logs mysql57
```

### 3. 进入容器执行恢复
```bash
# 进入MySQL容器
podman-compose exec mysql57 bash

# 在容器内执行恢复操作
```

### 4. 容器内恢复步骤
```bash
# 停止MySQL服务
mysqladmin -u root -p shutdown

# 等待服务完全停止
sleep 5

# 备份现有数据（如果存在）
if [ -d "/var/lib/mysql" ] && [ "$(ls -A /var/lib/mysql)" ]; then
    mv /var/lib/mysql /var/lib/mysql.backup.$(date +%Y%m%d_%H%M%S)
fi

# 创建新的数据目录
mkdir -p /var/lib/mysql
chown -R mysql:mysql /var/lib/mysql

# 使用mysqlbackup恢复数据
mysqlbackup --defaults-file=/etc/mysql/my.cnf \
            --backup-dir=/tmp/restore \
            --datadir=/var/lib/mysql \
            --backup-image=/backups/mysql57_sysafari_20250723.qp \
            copy-back-and-apply-log

# 设置正确的权限
chown -R mysql:mysql /var/lib/mysql

# 退出容器
exit
```

### 5. 重启服务
```bash
# 重启MySQL服务
podman-compose restart mysql57

# 验证恢复结果
podman-compose exec mysql57 mysql -u root -p -e "SHOW DATABASES;"
```

## 方法二：直接操作数据目录恢复

### 1. 停止MySQL服务
```bash
podman-compose down
```

### 2. 备份现有数据目录
```bash
# 如果数据目录存在且有数据，先备份
if [ -d "/data/databases/mysql/data" ] && [ "$(ls -A /data/databases/mysql/data)" ]; then
    mv /data/databases/mysql/data /data/databases/mysql/data.backup.$(date +%Y%m%d_%H%M%S)
fi
```

### 3. 创建临时容器进行恢复
```bash
# 创建临时容器用于恢复
podman run --rm -it \
    -v /data/databases/mysql/backups:/backups:ro \
    -v /data/databases/mysql/data:/var/lib/mysql \
    mysql:5.7 bash

# 在临时容器内执行
mkdir -p /var/lib/mysql
chown -R mysql:mysql /var/lib/mysql

mysqlbackup --defaults-file=/etc/mysql/my.cnf \
            --backup-dir=/tmp/restore \
            --datadir=/var/lib/mysql \
            --backup-image=/backups/mysql57_sysafari_20250723.qp \
            copy-back-and-apply-log

chown -R mysql:mysql /var/lib/mysql
exit
```

### 4. 启动MySQL服务
```bash
podman-compose up -d mysql57
```

## 验证恢复结果

### 1. 检查数据库连接
```bash
podman-compose exec mysql57 mysql -u root -p -e "SELECT VERSION();"
```

### 2. 验证时区设置
```bash
# 检查容器时区
podman-compose exec mysql57 date

# 检查MySQL时区设置
podman-compose exec mysql57 mysql -u root -p -e "SELECT @@global.time_zone, @@session.time_zone;"

# 运行时区验证脚本
./check-timezone.sh
```

### 3. 检查数据库列表
```bash
podman-compose exec mysql57 mysql -u root -p -e "SHOW DATABASES;"
```

### 4. 检查表数据
```bash
podman-compose exec mysql57 mysql -u root -p -e "USE sysafari; SHOW TABLES;"
```

### 5. 检查数据完整性
```bash
podman-compose exec mysql57 mysql -u root -p -e "USE sysafari; SELECT COUNT(*) FROM information_schema.tables WHERE table_schema = 'sysafari';"
```

## 故障排除

### 1. 权限问题
如果遇到权限错误：
```bash
# 修复数据目录权限
sudo chown -R 999:999 /data/databases/mysql/data
```

### 2. 备份文件格式问题
如果备份文件不是.qp格式：
```bash
# 对于.sql格式的备份文件
podman-compose exec mysql57 mysql -u root -p sysafari < /backups/backup.sql

# 对于.gz压缩的备份文件
gunzip -c /backups/backup.sql.gz | podman-compose exec -T mysql57 mysql -u root -p sysafari
```

### 3. 内存不足
如果恢复过程中内存不足：
```bash
# 增加容器内存限制
# 在mysql-bak-db.yaml中修改deploy.resources.limits.memory
```

### 4. 磁盘空间不足
检查磁盘空间：
```bash
df -h /data/databases/mysql/
```

## 安全建议

1. **密码安全**：修改默认密码，使用强密码
2. **网络安全**：限制数据库访问IP
3. **备份策略**：定期备份数据库
4. **监控**：设置数据库监控和告警

5. 定期测试恢复流程
