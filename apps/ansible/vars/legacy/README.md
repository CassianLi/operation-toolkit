# Legacy 变量（已上线机器）

本目录仅服务 `playbooks/legacy/`。新机请用上级目录的 `simple_users.yml` + `system_simple.yml`。

| 文件 | 用途 |
|------|------|
| `users.yml` / `groups.yml` / `system.yml` | 旧账户与 developers 等目录属组 |
| `root_users.yml` / `cleanup_users.yml` | 旧 root 档清单与清理 |
| `*.example` | 可提交的模板 |

实配文件勿提交。勿把此处目录属组策略套到 simple 新机。
